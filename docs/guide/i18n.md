# Localization & RTL

## Messages

The library ships two complete message packs, `en` and `tr`. Every user-visible string — the search
placeholder, pager labels, state texts, error messages, screen-reader announcements — comes from
the pack; modules (column menu, selection, export, row actions…) carry their own small packs in the
same two languages.

```js
import { Datagrid, configure, en } from "@akinozgen17/datagrids";

// one grid
new Datagrid("#agents", { columns, messages: { empty: "No agents yet", retry: "Try again" } });

// every new grid
configure({ messages: { search: "Find…" } });
```

Overrides are partial and merged over the pack; `undefined` values never replace a string. Some
messages are functions because they include numbers, e.g.
`info: (from, to, filtered, total) => string`. The complete key list is in the
[messages reference](/reference/messages). Module strings are overridden with each module's own
`messages` option.

## Which language?

The grid resolves its locale once, at construction:

1. the `locale` option,
2. `configure({ locale })`,
3. `<html lang>`,
4. otherwise `"tr"`.

Locales starting with `tr` use the Turkish pack, everything else the English one. Set `<html lang>`
(you should anyway — it also drives correct uppercasing of headers) or pass `locale`.

## Search and sort follow the locale

- **Search** folds case and accents with the grid's locale: `isik` finds `Işık`, `ISIK` finds
  `ışık`; every word must match (`raccoon north` → rows containing both).
- **Sorting** uses `Intl.Collator(locale, { numeric: true })`: `İ` sorts after `I`, `item 10` after
  `item 9`.
- **Numbers, money and dates** are formatted with the grid locale unless the column gets its own
  `locale`; money uses `TRY` unless you pass `currency`. Pager and info numbers use the grid locale.

## Right-to-left

The stylesheet uses logical properties only (`margin-inline-start`, `inset-inline-end`…), so a grid
inside `dir="rtl"` mirrors itself: toolbar, sort icons, sticky action column (moves to the left),
pager arrows and panels.

<Demo id="guide-i18n-rtl" />

Text cells are written with `dir="auto"`, so Latin data inside an RTL page keeps its punctuation in
place (`S.T.A.R.S.` doesn't become `.S.T.A.R.S`), and formatted numbers, money and dates are
bidi-isolated left-to-right blocks.
